# Démarrer ProdByYou

1. Extrais le ZIP.
2. Installe Node.js LTS si nécessaire.
3. Sur Windows, double-clique sur **Lancer ProdByYou.cmd** et laisse la fenêtre ouverte.
4. Dans le navigateur, compose avec Élan, importe un morceau ou démarre une production vide.

Les sauvegardes sont dans `%LOCALAPPDATA%\ProdByYou` sous Windows.
Pour récupérer une production de LYES, exporte-la en `.lyes`, puis importe-la dans ProdByYou.
